Installation & Setup

Follow these steps to install and run the project locally:

npm install
npm run dev

🗄️ Database Setup (MongoDB)

Make sure you create a MongoDB database that matches the schemas defined in the Backend Models folder.

Use MongoDB Atlas or a local MongoDB instance

Ensure all collections follow the structure used in the backend models

Add your MongoDB connection string to the environment variables

Example:

MONGO_URI=your_mongodb_connection_string

✅ Notes

Ensure MongoDB is running before starting the backend

The backend models define the required database structure
